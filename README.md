# فم الملاح — قراءات المناسيب

قراءات منسوب **الخلف** و**الأمام** عند فم الملاح (الغربية)، من إيميلات التليمتري، بتتحدث كل ساعة.

- `data.json`: آخر 7 أيام. كل قراءة: `k` (التاريخ_الساعة)، `d` التاريخ، `h` الساعة، `f` الأمام، `b` الخلف (متر). القيمة `null` يعني مفيش قراءة.
- تطبيق «فم الملاح» على أندرويد بيقرا الملف ده.
